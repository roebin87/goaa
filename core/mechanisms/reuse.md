# Mechanism · Reuse (Generic · V1.0 EN)

> Reuse = physical exponentiation of the index — methodologies/rules "produced" are inventory; only when loaded and invoked again are they assets.

## The three-stage loop

```
Production · asset registration → Consumption · reuse retrieval → Value · reuse-rate monitoring
```

## Three-in-one verification

| Field | Criterion |
|-------|-----------|
| Internal (rules↔mechanisms separation) | Runs without decay = reusable |
| External (world mirror / fact check) | Direction right = worth reusing |
| Anchored comparison | No anchor = self-comparison self-congratulation |

## Three exits

Reusable → asset library ／ needs revision → problem gate ／ abandoned → version retirement.
