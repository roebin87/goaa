# IDENTITY.md · Template (Workspace Structure Map)

> **Purpose**: tells the AI what each folder in your workspace does — structure is the manual.

## Workspace Structure (Lite release)

```
lite/ (your workspace root)
├── README.md                # Facade: how to start, what it's for
├── constitution/            # Core principles (highest agreement)
├── templates/               # Templates (activation generates your dedicated files)
│   ├── identity/            #   ├── your AI companion setup (becomes identity/ after activation)
│   └── memory/              #   └── memory templates (become _Memory/ after activation)
├── mechanisms/              # Flows: startup / wrap-up / onboarding
├── tools/                   # Tools: ownership verification script
└── docs/                    # Documentation
```

## Changes After Activation

After the first-activation onboarding completes, your dedicated files are generated:

| Template Location | Activated To | Content |
|---------|-----------|------|
| `templates/identity/` | `identity/` | your profiles + AI companion portrait + behavior covenant |
| `templates/memory/` | `_Memory/` | distillation + dialogue record (your memory starts accumulating) |

## Principles

- Your memory files (`_Memory/`) are **append-only, never edited/deleted**
- If the structure is unclear, ask the AI — it explains against this file
