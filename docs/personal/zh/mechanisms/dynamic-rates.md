# 机制 · 动态率监测（通用版 · V1.0）

> 体系的健康状态不可直接观测——用"率"让它可见。动态率=当前运转平衡态的监测仪表。

## 五原则
> **语义形态**：机语义（机制翻译层·How）

1. **锚定不动层**——率必须锚定真宪法（决断权在人）
2. **单一职能**——当前运转平衡态仪表，不做跨版本体检
3. **提前触发**——率趋势上升即干预，不等恶化
4. **防退化**——率不刷新会退化成度（定期采集是生命线）
5. **双面观测**——内部面（内部显影熵增）+外部面（外部对照校准）

## 率项分层

| 层 | 率项 | 说明 |
|----|------|------|
| 结果层 | 交付准时率/一次通过率/返工复发率 | 工作结果质量 |
| 输入层 | 待裁决积压率/物理化落地率 | 输入是否顺畅 |
| 平衡层 | 熵负平衡率 | 负熵注入÷熵增（统摄指标） |
| 熵增层 | 存量污染指数 | 规则膨胀+死链+漂移加权（版本选择判据） |
| 价值层 | 资产复用率/复用深度/复用转化率 | 唯一直接测"价值积累"的率 |

## 双锚

- **主锚**：元规则（决断权在人——权还在不在人）
- **辅锚**：公知（方向对不对——防自嗨）

## 采集机制

- **内部面**：歧义治理显影（数据现成·零新造）
- **外部面**：外部对照（世界之镜/事实核验/共识锚定）

## 干预流程

```
率采集 → 率趋势 → 异常？→ 是 → 定位层 → 判定（人终裁）→ 干预 → 再采集
                    └→ 否 → 健康（继续）
```

## 边界

- 率=信息非判断（人终裁）
- 阈值待校准（以运行代核验）
- 熵不可直接判定——判定的是熵的显影（物理物证）：存量污染指数=体系熵的温度计（测水银膨胀非温度）
