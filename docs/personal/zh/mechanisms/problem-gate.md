# 机制 · 立项判定（通用版 · V1.0）

> 监察会入口——问题进入体系的第一道闸门：五筛判定，人终裁。

## 规则面（R）
> **语义形态**：机语义（机制翻译层·How）

- **R1 五筛判据**：机侧四筛（前提/两难/结构/价值）→ 人价值筛（唯一权威源）
- **R2 裁定权**：人终裁 + 双锚（元规则判母集·公知判方向）
- **R3 三出口**：真→立项 / 假→拦截 / 待定→挂起桶

## 真问题三关（判据）

1. **有前提撑着**——结论长在前提上，没前提的结论一律不收
2. **不是"对或错"假两难**——伪两难本身不成立，必先验前提
3. **问者真在求辨**——陈述句当陈述句接，不掰成命题去分析

## 判定流程（M1）

```
问题注入 → 机侧四筛（前提/两难/结构/价值）→ 人价值筛（唯一权威源）
  ├─ 真问题 → 立项（进入方法论生产）
  ├─ 假问题 → 拦截（不投入）
  └─ 待定 → 挂起桶（待更清晰后重审）
```

## 运转挂点（M2）

- 启动 STEP4（指令双检）
- 探讨定论入口

## 率项反馈（M3）
