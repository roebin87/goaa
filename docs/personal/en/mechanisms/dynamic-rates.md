# Mechanism · Dynamic Rates (Generic · V1.0 EN)

> The system's health cannot be observed directly — rates make it visible. Dynamic rates = the instrument panel of the current operating equilibrium.

## Five principles
> **Semantics**: Machine (mechanism/translation layer · How)

1. Anchor to the immutable layer (decision rights with the human)
2. Single function (current equilibrium only)
3. Trigger early (intervene when a trend rises)
4. Prevent decay (refresh regularly)
5. Two faces (internal surfaced entropy + external calibration)

## Rate layers

Result (delivery/first-pass/rework) · Input (backlog/physicalization) · Balance (negative-entropy balance) · Entropy (stock pollution index) · Value (reuse rates — the only direct measure of value accumulation)

## Use discipline

Rates are a dashboard for finding problems, not a whip for punishment — rate anomaly = find root cause, surface to the human, human decides whether to correct the mechanism.
