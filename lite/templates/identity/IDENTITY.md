# IDENTITY.md · 模板（工作区结构地图）

> **用途**：告诉 AI 你的工作区里每个文件夹是干什么的——结构即说明书。

## 工作区结构（lite/）

```
lite/（你的工作区根）
├── README.md                # 门面：怎么开始、有什么用
├── constitution/            # 核心原则（最高约定）
├── templates/               # 模板（激活时生成你的专属文件）
│   ├── identity/            #   ｜── 你的 AI 伙伴设定（激活后变成 identity/）
│   └── memory/              #   └── 记忆模板（激活后变成 _Memory/）
├── mechanisms/              # 流程：启动/收摊/引导
├── tools/                   # 工具：所有权验证脚本
└── docs/                    # 说明文档
```

## 激活后的变化

首次激活引导完成后，会生成你的专属文件：

| 模板位置 | 激活后落位 | 内容 |
|---------|-----------|------|
| `templates/identity/` | `identity/` | 你的档案 + AI 伙伴画像 + 行为约定 |
| `templates/memory/` | `_Memory/` | 蒸馏 + 对话记录（你的记忆开始积累） |

## 原则

- 你的记忆文件（`_Memory/`）**只追加不删改**
- 结构不明白就问 AI，它会对照本文件解释
