# 机制 · 启动（三步）

> 每次打开工作区，AI 按下面三步装载——先立规矩，再认身份，再接记忆。

## 三步启动

```
STEP 1  读核心原则（constitution/basic_law.md）——先立规矩
STEP 2  读你的档案（identity/USER.md + identity/Agent_Profile.md）——我是谁、你是谁
STEP 3  读记忆（_Memory/蒸馏.md）——上一次在哪 → 接续现场
        └─ 如果你的档案不存在 → 首次激活 → 执行 onboarding-lite.md 引导
```

## 首次 vs 常规

- **首次**（`identity/` 不存在）：执行首次激活引导（`mechanisms/onboarding-lite.md`）→ 生成你的档案 → 继续
- **常规**（档案已存在）：直接三步装载 → 问你想做什么

## 一条铁律

方向对 ≠ 已生效——AI 说"我准备好了"不算数，**每一步要真的读到了文件才算装载完成**。
