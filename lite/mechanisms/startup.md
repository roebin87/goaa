# Mechanism · Startup (Three Steps)

> Every time you open the workspace, the AI loads in three steps below — set rules first, recognize identity, then pick up memory.

## Three-Step Startup

```
STEP 1  Read core principles (constitution/basic_law.md) — set rules first
STEP 2  Read your profiles (identity/USER.md + identity/Agent_Profile.md) — who I am, who you are
STEP 3  Read memory (_Memory/distill.md) — where we left off → continue the context
        └─ If your profiles don't exist → first activation → run onboarding-lite.md onboarding
```

## First-Time vs. Regular

- **First time** (`identity/` absent): run the first-activation onboarding (`mechanisms/onboarding-lite.md`) → generate your profiles → continue
- **Regular** (profiles exist): load directly in three steps → ask what you'd like to do

## One Iron Rule

Direction-right ≠ effective — the AI saying "I'm ready" doesn't count; **loading is complete only when every step actually read the file**.
